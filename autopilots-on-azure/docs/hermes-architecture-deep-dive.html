Reachability is not authorization

  • Managed identity: Azure execution, lifecycle, telemetry, and native Foundry inference according to the service role's grants.
  • Agent Identity: autonomous custom MCP calls and native cron's Service Bus send.
  • Agent User: the Worker's licensed Microsoft 365 account, access, and action attribution.

The loopback MCP adapter obtains a workload assertion, exchanges through the blueprint federated credential using fmi_path, and requests the target audience. Microsoft 365 access adds the fixed Agent User exchange through user_fic. Tokens are short-lived; the agent does not receive bearer-token text. This is not human on-behalf-of delegation.

Token exchange and MCP adapter · Worker role assignments

Hermes connects to loopback MCP endpoints. The adapter selects the business identity and upstream route. Private incidents use the Sandbox network connection, peering, private DNS, and a linked private endpoint; public shipments use HTTPS.

Both custom servers validate tokens for their configured tenant, issuer, audience, caller, and required role. Network reachability does not grant application access. The gateway is not a relay for this tool traffic.

Work IQ handles supported discovery, reading, creation, and comments. The collaboration adapter supplies Agent User file access, Excel range operations, and same-item uploads. Pinned document skills and format tools handle local transformations.

  1. AcquireResolve access, download bytes, retain the ETag.
  2. Edit and validateCheck the intended change and package integrity.
  3. PublishUpdate the original only against its expected ETag.

A locked edit is staged privately for one hour by default. Choosing background publication starts a separate 24-hour retry deadline and retains the file for one further hour for completion/cleanup. Teams actions select retrying the original or sharing a copy; retries do not start another model turn. See the document contract for configuration and receipt retention.

ETag conflicts are not silently overwritten. Attachment content is turn-scoped and excluded from durable learning; pending publication is a separate bounded retention path. External message delivery is not exactly-once.

State outlives execution

The profile contains native memory and history, private skills, governed role/candidate skills, learning records, schedules, and working files. A pinned Role Release provides the baseline against which local governed changes are tracked.

A healthy stopped or suspended Sandbox resumes with the same ID. A failed runtime can be replaced while preserving its Data Disk. A profile refresh is a separate governed operation, not an automatic side effect of a new image.

Deploy and diagnose explicit boundaries

  1. TerraformCreates infrastructure, identities, networking, and configuration.
  2. Build and convertPins dependencies and converts each service image once.
  3. Deploy servicesUses disk-image IDs, then records healthy endpoints.

ACR conversion uses a short-lived token from az acr login --expose-token because the current managed-identity conversion path fails. ACR admin is disabled. Reusing a prepared image does not acquire another registry token.

Decision and SDK issue · Conversion implementation · Commands and owner preflight

Application Insights receives metadata-only OpenTelemetry spans. Worker and session attribution connect the gateway request, runtime invocation, model calls, and tools. Prompts, responses, bearer tokens, and tool payloads do not belong in this trace stream.

The Foundry external-agent registration links this execution to its monitoring surface. Registration does not move the agent into Foundry hosting or establish evaluation quality.

The Sandbox-origin egress path preserves TraceId but can rewrite ParentId; its intermediate platform span is not available in application telemetry. Correlation is therefore useful without a complete platform-hop tree. The native /v1/responses path also lacks explicit session correlation.

An interrupted native handoff retains its lease to prevent misattributing later spans. Restart the affected wrapper/native runtime processes before reuse; do not fabricate a parent span or silently clear the fence.

Source

Telemetry policy · Native handoff · Foundry registration

  • Stopped service: resume the matching Sandbox instead of replacing it.
  • Failed service: create a healthy replacement before retiring the prior resource.
  • Unknown Dream outcome: surface the fenced phase; do not rerun the model automatically.
  • Changed governed state: require a new packet and approval, not an old receipt.
  • Missing endpoint ownership: fail preflight before Agent 365 registration is mutated.
