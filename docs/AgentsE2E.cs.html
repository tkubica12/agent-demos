Pět stupňů agentních řešení

Od odpovědi
ke sdílené odbornosti.

Nejde jen o autonomii, ale i kontinuitu a přenos schopností.

  1. ChatbotOdpovídá nebo připraví návrh. Další akci provede člověk.
  2. WorkflowProvádí předem určený proces. AI může řešit jednotlivé kroky.
  3. Osobní pracantZvolí postup, použije nástroje, splní zadaný úkol a skončí.
  4. Digitální kolegaDlouhodobě drží roli a stav, reaguje na události a učí se ze zkušenosti.
  5. Sdílená odbornostPřevádí postupy expertů do znovupoužitelných skills pro další týmy.

Ilustrativní kampaň: chatbot navrhne slogan; workflow zajistí schválení; osobní pracant vytvoří a nahraje kampaň; digitální kolega sleduje výkon a upravuje ji v mezích zadání; sdílená odbornost předá osvědčený postup dalším týmům jako skill.

Zdroje

Autorský model pěti stupňů; adaptace původního příkladu kampaně.

Platforma

Runtime

Runtime vykonává kroky. Harness řídí pracovní smyčku.

Runtime vykonává kroky; harness zajišťuje smyčku s kontextem, nástroji a pravidly. Hranice s frameworky se překrývají.

  • Microsoft Agent Framework / LangGraph: skládání agentů a workflow v kódu, včetně běhové podpory.
  • GitHub Copilot harness, OpenClaw, Hermes: hotovější smyčka, nástroje a stav.
  • Copilot Studio: například standardní či GitHub Copilot harness; Foundry: prompt/hosted agents.

Workflow Copilot Studia umí spustit úlohu Cowork (preview). Autopilots: průběžní agenti s vlastní identitou; Microsoft Scout byl oznámen v private preview.

Zdroje

Agent Framework; LangGraph; Copilot harness; Copilot Studio; OpenClaw; Hermes; Cowork; Scout.

Landing zone

  • Prostředí, přístup a limity pro AI
  • Foundry: projekty a modely
  • AI gateway: společná brána v Azure API Management

Landing zone vymezuje projekty, síť, identity, kapacitu a rozpočty. Brána sjednocuje přístup k modelům a nástrojům, hlídá limity a sbírá telemetrii. Ověřte, že ji provoz nemůže obejít.

Microsoft Foundry zajišťuje projekty a modely. AI gateway v Azure API Management (APIM) přidává společnou bránu pro modely a nástroje.

Zdroje

Foundry; AI gateway v APIM.

Hosting

  • Izolovaný pracovní prostor pro kód a soubory
  • Copilot Studio a Foundry: spravovaný hosting
  • Container Apps Sandboxes či AKS: větší provozní odpovědnost

Hosting zajišťuje běh, izolaci, škálování a obnovu. Pro práci s kódem a soubory potřebuje agent izolovaný pracovní prostor — sandbox pro uživatele či relaci, nikoli nutně fyzický počítač.

Copilot Studio hostuje agenty; Foundry nabízí prompt agents i hosted agents s vlastním kódem a izolací relací. Azure Container Apps Sandboxes či AKS dávají větší kontrolu, ale také odpovědnost za provoz.

Zdroje

Foundry hosted agents; Container Apps Sandboxes.

Propojení

Nástroje

  • MCP připojuje nástroje; A2A deleguje agentům
  • Každá akce potřebuje autorizaci
  • Foundry Toolboxes a APIM: spravované propojení

Model Context Protocol (MCP) připojuje nástroje a zdroje; Agent2Agent (A2A) propojuje samostatné agenty pro delegování úkolů. Běžná API mají stále své místo. Každá akce potřebuje autorizaci u zdroje, důležité zápisy i schválení a idempotentní opakování.

Foundry Toolboxes sdružují nástroje za spravovaným MCP endpointem; APIM řídí provoz, katalog pomáhá s objevováním. Microsoft Entra může zajistit OAuth pro chráněné HTTP MCP, protokol ji ale nepředepisuje. Zdroj ověřuje token, cílové publikum, oprávnění i obchodní pravidla.

Zdroje

A2A a MCP; Autorizace MCP; Foundry Toolbox.

Znalosti

  • Microsoft IQ: relevantní kontext podle oprávnění
  • Foundry Memory: profily, shrnutí, procedurální paměť
  • Foundry Toolboxes: sdílené, verzované skills

Znalosti spojují autoritativní zdroje, paměť zkušeností a znovupoužitelné postupy. Zachovejte oprávnění, citace a pravidla uchování i mazání.

Kontext podle Microsoft IQ:

  • Work IQ: lidé a pracovní kontext v Microsoft 365.
  • Foundry IQ: znalostní báze a agentní vyhledávání nad Azure AI Search.
  • Fabric IQ: obchodní entity, vztahy a řízené sémantické modely.
  • Web IQ: aktuální kontext z veřejného webu.

Foundry Memory (preview) uchovává profily uživatelů, shrnutí konverzací a procedurální paměť; kontext aktuální relace drží runtime. Foundry Toolboxes centrálně spravují verzované skills (preview), tedy znovupoužitelné postupy.

Zdroje

Work IQ; Foundry IQ; Fabric IQ; Web IQ; Memory; Toolbox a skills.

Kanály

  • Konverzace a předání identity, ne logika agenta
  • Teams: @zmínky i ve skupinách a kanálech
  • Agent 365: notifikace z komentářů Wordu po zapojení

Kanál doručuje konverzaci, neřídí logiku ani oprávnění agenta. Ověřte streaming, přílohy, schvalování a delegovanou autentizaci.

Foundry a Copilot Studio publikují do Teams a Microsoft 365 Copilot; vlastní integrace využívají Microsoft 365 Agents SDK. Agent v Teams může reagovat na @zmínky ve skupinách i kanálech. Agent 365 s agent user účtem a zapojenými notifikacemi zpracuje i @zmínku v komentáři Wordu.

Zdroje

Publikování z Foundry; Teams @zmínky; Agent 365 notifikace.

Řízení a důvěra

Identita

  • OBO: za přihlášeného člověka
  • S2S: vlastní aplikační oprávnění
  • Agentic-User: vlastní uživatelský účet agenta

Rozlišujte, za koho agent jedná. Vždy přidělte jen potřebná oprávnění a umožněte jejich odvolání.

  • OBO (on-behalf-of): za přihlášeného uživatele s delegovanými oprávněními; například osobní pracant.
  • S2S: pod vlastní aplikační identitou a oprávněními; například workflow na pozadí.
  • Agentic-User: vlastní uživatelský účet agenta; po zřízení a licencování také schránka, kalendář a týmová spolupráce.

Zdroje

Tři režimy identity; Entra Agent ID.

Governance

  • Vlastník, schválení, monitoring a vyřazení
  • Agent 365: řízení napříč organizací
  • Foundry: vývoj a provoz

Každý agent potřebuje vlastníka, schválený účel, monitoring a možnost zablokování či vyřazení. Inventář ukazuje, co existuje; sám ale nevynucuje pravidla.

Agent 365 poskytuje podnikový inventář a governance s integrací na Entra, Purview a Defender. Foundry zajišťuje vývojové a provozní řízení. Zvolte vestavěnou integraci, synchronizaci registru nebo schopnosti Agent 365 SDK a ověřte licence i pokrytí. Registrace automaticky nezapíná nástroje, telemetrii ani ochrany.

Zdroje

Agent 365; Agent 365 SDK.

Ochrana dat

  • Vstupy, výstupy, paměť i logy
  • Purview: audit, klasifikace, DLP a compliance
  • Nový obsah automaticky nedědí štítky

Ochrana dat zahrnuje vstupy, výstupy, paměť i logy. Respektujte oprávnění zdrojů a testujte povolený i zamítnutý přístup, včetně výsledků vyhledávání, vytvořených souborů a telemetrie.

Purview poskytuje audit, klasifikaci, prevenci úniku dat (DLP) a compliance pro podporované cesty. Zahrňte agenty do politik; vlastní aplikace potřebují integraci.

Zdroje

Pokrytí a omezení Purview; Integrace vlastní aplikace.

Bezpečnost agentů

  • Nedůvěryhodné vstupy, omezené nástroje, schvalování
  • Foundry guardrails: blokování i anotace podle typu kontroly
  • Defender blokuje podporované akce podle nastavených pravidel

Načtený obsah považujte za nedůvěryhodný. Omezte oprávnění nástrojů a odchozí komunikaci, významné akce podmiňte schválením člověka. Filtry nenahrazují obchodní autorizaci ani bezpečnostní evaluace.

Foundry guardrails pokrývají škodlivý obsah, prompt injection i osobní údaje (PII). U modelů lze nálezy blokovat či anotovat; spotlighting v Chat Completions označuje dokumenty jako méně důvěryhodné. Anotace využijte v telemetrii k filtrování a vyloučení citlivých záznamů z evaluací.

Defender kontroluje podporované akce před provedením: výchozí cloudové pravidlo audituje, blokování vyžaduje vlastní pravidla. Pokrytí Copilot Studio a Foundry zahrnuje preview funkce. Ochrana nástrojů v Agent 365 závisí na integraci Work IQ MCP; nepodporované cesty nechrání.

Zdroje

Guardrails; PII; Spotlighting; Defender.

Provoz a zlepšování

Observabilita

  • Traces: co se stalo, proč a za kolik
  • Zpětná vazba: palec nahoru/dolů
  • Foundry: z provozních konverzací k evaluačním sadám

Propojte volání agenta, modelu a nástrojů s verzí a výsledkem, například pomocí OpenTelemetry. Sledujte dokončení, eskalace, chybovost, latenci a celkovou cenu úspěšného úkolu. Minimalizujte citlivý obsah a nastavte retenci.

Foundry nad Application Insights pomáhá vývojářům dohledat kroky a problematické konverzace. Z aplikace připojte palec nahoru/dolů a podle zpětné vazby filtrujte interakce. Z provozních traces umí Foundry vytvořit evaluační sadu (preview); před použitím zkontrolujte její obsah.

Zdroje

Anotace a zpětná vazba; Datasety z traces.

Evaluace

  • Splnění úkolu, bezpečnost, spolehlivost a cena
  • Copilot Studio: testovací sady ve standard harness
  • Foundry: vestavěné i vlastní evaluátory

Udržujte reprezentativní případy s očekávaným výsledkem, povolenými akcemi a kritérii selhání. Ověřujte oporu ve zdrojích, parametry nástrojů, hranice oprávnění, prompt injection, obnovu, latenci i cenu. Kombinujte deterministické kontroly s kalibrovaným hodnocením modelem a lidskou kontrolou.

Standard harness v Copilot Studio podporuje evaluace testovacích sad; Foundry nabízí vestavěné i vlastní evaluátory včetně dokončení úkolu a přesnosti volání nástrojů. Vyhodnocujte před nasazením a následně na vzorku provozních traces. Agent Optimizer je preview; automatické zlepšování stále potřebuje nezávislé regresní kontroly.

Zdroje

Foundry evaluace; Agent Optimizer; Copilot Studio evaluace.

CI/CD

  • Verze, kontroly, postupné nasazení a rollback
  • Copilot Studio: solutions a pipelines
  • Foundry: infrastruktura jako kód, SDK/API a Dev Pack

Verzujte prompty, modely, schémata nástrojů, skills, konfiguraci znalostí, kód i evaluační sady. Povyšujte ověřené verze, sledujte změny a zachovejte rollback. Změny coding agentů před nasazením zkontrolujte a otestujte.

Copilot Studio využívá Power Platform solutions a pipelines; Foundry infrastrukturu jako kód a nasazení přes SDK/API. Foundry Dev Pack sdružuje nástroje pro implementaci, nasazení a evaluace.

Zdroje

Foundry Dev Pack; Životní cyklus Foundry.
