# Microsoft Foundry Technical Workshop

## Build, evaluate and operate custom enterprise agents on one platform

**Format:** Full-day, Microsoft-led technical workshop  
**Audience:** Engineering leaders, architects, AI engineers, data engineers and developers  
**Approach:** High-impact technical demonstrations, guided hands-on exploration and architecture discussion

## Workshop focus

This workshop is for teams **building custom agents and AI solutions with code**, models, enterprise data and APIs. It follows the professional builder journey from development to production operations while demonstrating choice across Microsoft and third-party frameworks, proprietary models and open models.

## Workshop goals

By the end of the day, participants will understand how Microsoft Foundry can:

- use **Microsoft Agent Framework, LangGraph and other frameworks** with a choice of proprietary and open models;
- run custom agents as managed **Foundry hosted agents** with identity, scale, sessions and integrated operations;
- ground agents with **Foundry IQ** and connect them safely to enterprise tools through MCP and Toolboxes;
- measure and improve quality through **tracing, evaluations, monitoring and red teaming**;
- evaluate and optimize **model choice** using quality, latency, cost and operational evidence;
- connect custom agents to Microsoft 365 and govern them with **Microsoft Agent 365**;
- meet enterprise requirements through **identity, data boundaries, governance and platform controls**.

## Chapter format

Every technical chapter follows the same rhythm:

1. **See it:** A focused demonstration of the complete experience, including advanced capabilities that are too slow or fragile to build during the workshop.
2. **Work with it:** A guided hands-on segment in a pre-provisioned environment, focused on one meaningful technical outcome.
3. **Connect it:** An architecture and adoption discussion linking the experience to enterprise controls, operational ownership and your own use cases.

## Hands-on storyline

Participants will progressively **create, govern, ground, observe, evaluate and improve an enterprise agent** using a prepared environment. They will:

- create a simple prompt-based agent;
- choose between models from different vendors against a machine-checkable contract, and apply a guardrail policy to a versioned agent;
- follow prepared agent code from local development to a demonstrated Foundry hosted deployment;
- create a Foundry IQ knowledge base and grounded agent;
- inspect traces, run evaluations and improve the agent;
- see how the resulting solution is hardened for enterprise operation.

The final business scenario and optional integrations are selected during preparation. Hands-on exercises will use synthetic data and pre-provisioned resources so every participant has a simple, reliable path to completion.

## Expected outcomes

Participants will leave with:

- practical experience building, grounding, evaluating and improving an enterprise agent;
- a clear understanding of where Foundry provides value beyond an agent SDK or model endpoint;
- an architecture view covering models, runtime, context, tools, operations and governance;
- a realistic position on Microsoft Agent 365, Microsoft 365 publishing and emerging Autopilot experiences;
- initial ideas for suitable use cases and practical next steps.
