# Progressive Agents

A runnable, step-by-step exploration of Microsoft Foundry and Microsoft Agent Framework.

Each numbered directory copies the previous working stage and adds one clearly isolated capability. The agent stays intentionally small so the effect of each Foundry feature remains visible.

See [PLAN.md](PLAN.md) for the roadmap and boundaries. The latest implemented
stage is
[11 - Agent 365 and Teams](11-agent365-teams/README.md); its Teams acceptance
is not yet complete (see its
[current deployed boundary](11-agent365-teams/README.md#current-deployed-boundary)).
